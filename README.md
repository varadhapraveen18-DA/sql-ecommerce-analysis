# E-Commerce SQL Data Analysis Project

## Project Overview

This project analyzes e-commerce sales data using SQL.
The goal of this project is to practice SQL concepts used in real data analyst jobs and solve business-related problems using queries.

---

## Tools Used

* MySQL
* SQL
* VS Code
* GitHub

---

## SQL Concepts Used

* SELECT
* WHERE
* JOIN
* GROUP BY
* HAVING
* ORDER BY
* LIMIT
* DISTINCT
* BETWEEN
* LIKE
* Aggregate Functions (SUM, COUNT, AVG, MAX, MIN)

---

## Database Tables

### Customers Table

Contains customer details such as:

* customer_id
* customer_name
* city

### Products Table

Contains product details such as:

* product_id
* product_name
* category
* price

### Orders Table

Contains transaction/order details such as:

* order_id
* customer_id
* product_id
* quantity
* order_date

---

## Business Problems Solved

* Total quantity sold
* Total revenue generated
* Revenue by category
* Top spending customers
* Highest and lowest priced products
* Unique customer cities
* Products within price range
* Customer name pattern analysis

---

## Key Learning Outcomes

* Understanding JOIN operations
* Writing business-focused SQL queries
* Using aggregate functions for analysis
* Grouping and filtering data
* Building SQL projects for portfolio
